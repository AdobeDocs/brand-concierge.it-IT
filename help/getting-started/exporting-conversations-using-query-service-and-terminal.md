# Esportazione di conversazioni tramite servizio query e terminale

Scopri come salvare ed esportare conversazioni Adobe Brand Concierge utilizzando Adobe Experience Platform Query Service e Terminal. Questo video mostra come trovare i nomi delle tabelle dei set di dati, configurare il client della riga di comando PostgreSQL ed esportare i dati di conversazione per un intervallo di date in un file CSV.

## A chi serve questo video?

* Sviluppatori che devono esportare i dati di conversazione di Brand Concierge utilizzando gli strumenti della riga di comando

## Contenuto video

* Trovare i set di dati di conversazione in Experience Platform e copiarne i nomi di tabella
* Installare il client PostgreSQL con Homebrew e configurarne il percorso della riga di comando
* Copiare il comando di connessione PSQL dalla scheda Credenziali del servizio query
* Seleziona un set di dati e un intervallo di date, quindi esporta i risultati della query in un file CSV locale
* Controlla i risultati esportati e aggiorna le credenziali scadute quando necessario

>[!VIDEO](https://video.tv.adobe.com/v/3504643)

>[!IMPORTANT]
>
> Il comando di connessione PSQL contiene una password attiva. Non condividerlo né incollarlo in chat, agenti di intelligenza artificiale o e-mail. Se l&#39;autenticazione non riesce dopo la scadenza della password, copiare un nuovo comando dalla scheda Credenziali del servizio query.

>[!NOTE]
>
> Le conversazioni esportate possono contenere dati personali (PII, personally identifiable information). Segui le regole aziendali di gestione dei dati per l’archiviazione dei file CSV.

Per la documentazione, consulta [Guida di Brand Concierge](../documentation/overview.md).
